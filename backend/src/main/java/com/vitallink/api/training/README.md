# Training

Exercise catalogue, workouts with sets (synced workouts update instead of duplicating), training plans,
and the training view (weekly load, sessions with pace/zone/PR, muscle balance, personal records).

- `POST/GET /me/workouts`, `GET/DELETE /me/workouts/{id}`, `GET /me/training`
- `POST/GET /me/training/plans`, `GET /exercises`

Tables: `exercises`, `workouts`, `exercise_sets`, `training_plans`, `plan_sessions`.
